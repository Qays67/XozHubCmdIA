1Comment on installe

Ouvre l'invite de commandes (touche Windows, tape cmd, Entrée), colle la ligne ci-dessus (clic droit = coller), puis Entrée. Laisse la fenêtre ouverte une minute : tout se fait tout seul.

1

Node.js est vérifié

Si la version 18 ou plus manque, elle est installée automatiquement. Sinon le lien officiel t'est donné.

2

L'IA s'écrit sur le disque

Dans %LOCALAPPDATA%\XozHub. Le code voyage dans cette ligne : rien d'autre n'est téléchargé.

3

La commande est créée

xozhub est ajouté au PATH, et le raccourci XozHub.GPT est posé sur le Bureau.

4

Le dossier est masqué

Il ne contient aucun script lisible : le code y est chiffré, et seule l'icône du Bureau reste visible.

5

La clé est déjà dedans

Aucun compte à créer, aucun identifiant à taper : tu n'as rien à saisir.

2Lancer l'IA, et retrouver tes fichiers

▶

Double-clique sur l'icône XozHub.GPT

Elle est sur ton Bureau. La fenêtre s'ouvre, l'IA démarre, tu peux lui parler. C'est la façon la plus simple, et elle marche même si le PATH de Windows n'est pas encore à jour.

C:\> xozhub

Tes fichiers atterrissent là où tu le dis

5Si la ligne ne passe pas

Trois autres façons d'installer, pour les cas où le réseau ou l'antivirus s'en mêle.

1

Un seul fichier .cmd

On te l'envoie (Discord, mail, clé USB), tu double-cliques dessus : l'IA s'installe et s'ouvre. Rien n'est téléchargé, donc ni l'antivirus ni le réseau ne peuvent le bloquer.

2

XozHub-GPT-Setup.exe

Double-clique dessus : tout est dedans, rien n'est téléchargé. Windows affichera « Windows a protégé votre PC » (pas de signature payante) : clique sur Informations complémentaires → Exécuter quand même.

3

Un dossier ou un .zip

Décompresse le .zip, entre dans le dossier et double-clique sur install.cmd. La clé est déjà dans le dossier : rien à saisir.

6Ça ne marche pas ?

Cherche ton message dans la liste : chaque ligne donne la cause et le geste exact.

Erreur rouge tout de suite : la ligne n'a rien fait

La ligne n'a pas réussi à télécharger l'installation : ta connexion, un DNS filtrant, ou un réseau qui bloque github.com (école, entreprise).

Essaie depuis un autre réseau. Sinon, fais-toi envoyer le .exe ou le .zip : ils n'ont besoin d'aucun téléchargement.

« Le fichier d'installation est incomplet ou abîmé »

Le téléchargement s'est mal terminé. Relance la même ligne : elle reprend tout depuis le début.

Si ça recommence, c'est un antivirus ou un réseau qui coupe le fichier : passe par le .exe.

L'antivirus bloque ou supprime des fichiers

Un script qui télécharge et exécute du code, c'est aussi ce que fait un virus : certains antivirus le refusent, sans que ce soit une erreur de ta part.

Utilise le .exe (il ne télécharge rien), ou autorise le dossier %LOCALAPPDATA%\XozHub.

« 'xozhub' n'est pas reconnu en tant que commande »

Windows ne relit le chemin des commandes qu'à l'ouverture d'une fenêtre.

Ferme-la, ouvre-en une nouvelle, puis retape xozhub. Ça marche aussi tout de suite : double-clique sur le raccourci XozHub.GPT du Bureau.

« XozHub.GPT a besoin de Node.js 18 ou plus »

L'installation propose de l'installer pour toi : réponds O (Windows peut demander une autorisation).

Sinon, installe la version LTS depuis nodejs.org, puis relance la ligne.

« Aucune clé API détectée »

La clé X.GPT (xgpt_…) voyage dans l'installation : elle se pose toute seule.

Si ce message apparaît quand même, demande une clé à la personne qui t'a donné XozHub.GPT, puis relance l'installation.

L'IA répond mais ne crée pas mes fichiers

Vérifie que ta demande est bien une demande d'action (« crée… », « corrige… », « fais-moi… ») et pas une question.

Une phrase qui contient un « ? » reste une question, sauf si elle porte un verbe d'action : « tu peux me créer un site ? » déclenche bien le travail.

À l'inverse, si tu lui parles sans rien demander — « c'est joli », « j'aime pas le bleu », « ok merci beaucoup » — elle répond en texte et ne crée rien : aucun fichier, aucune commande. C'est voulu. Dis-lui « change-le » pour qu'elle passe à l'action.
