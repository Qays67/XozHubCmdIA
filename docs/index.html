XozHub.GPT.GPT

Agent de développement en ligne de commande : tu lui parles en français, il écrit les fichiers, exécute les commandes et vérifie son travail. Installation en une seule ligne, sur Windows.

1Colle cette ligne dans cmd

Ouvre l'invite de commandes (touche Windows, tape cmd, Entrée), colle la ligne ci-dessous (clic droit = coller) puis appuie sur Entrée :

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Qays67/XozHubCmdIA/main/install-en-ligne.ps1 | iex"

Rien à télécharger à la main, rien à décompresser, rien à taper d'autre. Laisse la fenêtre ouverte : ça prend une minute.

2Ce qui se passe

  1. elle vérifie Node.js 18+ et propose de l'installer automatiquement s'il manque ;
  2. elle installe l'IA dans %LOCALAPPDATA%\XozHub : le code voyage dans cette ligne, donc rien d'autre n'est téléchargé (pas de .zip, rien à décompresser) ;
  3. elle ajoute la commande xozhub et pose le raccourci XozHub.GPT sur ton Bureau ;
  4. elle masque le dossier et n'y dépose aucun script lisible : le code y est chiffré ;
  5. la clé X.GPT est déjà fournie dedans : tu n'as rien à saisir.

3Lancer l'IA

Deux façons, au choix :

  1. double-clique sur l'icône XozHub.GPT posée sur ton Bureau : l'IA s'ouvre dans une fenêtre de terminal (c'est la façon la plus simple, elle marche toujours) ;
  2. ou ouvre une nouvelle fenêtre cmd et tape :
xozhub

La commande marche ensuite depuis n'importe quel dossier. Si elle n'est pas trouvée, c'est que la fenêtre cmd était ouverte avant l'installation : ferme-la et rouvre-en une.

Ta première demande

Écris en français, avec tes mots, puis appuie sur Entrée. Par exemple :

crée une page de vente pour une appli de gestion de budget, dossier budget-app :
titre accrocheur, trois avantages, une section tarifs avec deux formules, un bouton
d'inscription, et un pied de page. Style moderne, dégradé violet à bleu

Il travaille tout seul : il crée le dossier, écrit les fichiers, lance un serveur local pour vérifier que la page répond, corrige ce qui ne va pas, puis écrit TERMINÉ.

Autres façons d'installer

Avec un fichier XozHub-GPT-Setup.exe (si on te l'a envoyé)

Double-clique dessus : tout est dedans, rien n'est téléchargé pendant l'installation. Windows affichera « Windows a protégé votre PC » (le programme n'a pas de signature payante) : clique sur Informations complémentaires → Exécuter quand même.

Avec un dossier ou un .zip du projet

Décompresse le .zip s'il y en a un, entre dans le dossier et double-clique sur install.cmd. La clé est déjà dans le dossier : rien à saisir.

Ça ne marche pas ?

« 'xozhub' n'est pas reconnu en tant que commande »

Windows ne relit le chemin des commandes qu'à l'ouverture d'une fenêtre. Ferme celle-ci et ouvre-en une nouvelle, puis retape xozhub. Autre méthode qui marche toujours : double-clique sur le raccourci XozHub.GPT du Bureau.

« XozHub.GPT a besoin de Node.js 18 ou plus »

L'installateur propose de l'installer automatiquement via winget : réponds O. Sinon, installe Node.js LTS depuis nodejs.org, puis relance l'installation.

La ligne ne fait rien, ou « le fichier d'installation est incomplet »

Vérifie ta connexion internet, puis relance la même ligne : elle retélécharge le fichier entier. Si le dépôt a été renommé ou passé en privé, la ligne ne marche plus pour personne — un dépôt public est obligatoire.

« Aucune clé API détectée »

La clé X.GPT (xgpt_…) voyage dans le .env du projet : elle s'installe toute seule. Si ce message apparaît quand même, demande une clé à la personne qui t'a donné XozHub.GPT et relance l'installation.

Où est installé XozHub.GPT, et comment le mettre à jour ?

Tout est dans %LOCALAPPDATA%\XozHub (dossier masqué par Windows : c'est normal, tu n'as rien à y faire), et la clé X.GPT est dans le .env de ce dossier. Dans l'interface, la commande /miseajour récupère la dernière version du code et de l'IA, puis redémarre : tu ne perds ni ta conversation, ni tes fichiers de travail.
