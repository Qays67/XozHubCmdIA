XozHub.GPT.GPT

Agent de développement en ligne de commande : tu lui parles en français, il écrit les fichiers, exécute les commandes et vérifie son travail. Installation en une seule ligne, sur Windows.

1Colle cette ligne dans cmd

Ouvre l'invite de commandes (touche Windows, tape cmd, Entrée), colle la ligne ci-dessous (clic droit = coller) puis appuie sur Entrée :

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Qays67/XozHubCmdIA/main/install-en-ligne.ps1 | iex"

Rien à télécharger à la main, rien à décompresser, rien à taper d'autre. Laisse la fenêtre ouverte : ça prend une minute.

2Ce qui se passe

  1. elle vérifie Node.js 18+ et propose de l'installer automatiquement s'il manque — sinon elle te donne le lien officiel ;
  2. elle installe l'IA dans %LOCALAPPDATA%\XozHub : le code voyage dans cette ligne, donc rien d'autre n'est téléchargé. Pas de .zip, rien à décompresser, aucun dossier à reconstituer ;
  3. elle ajoute la commande xozhub et pose le raccourci XozHub.GPT sur ton Bureau ;
  4. elle masque le dossier et n'y dépose aucun script lisible : le code y est chiffré ;
  5. si une version plus ancienne était déjà installée, elle est remplacée et ses anciens scripts lisibles sont effacés ;
  6. la clé X.GPT est déjà fournie dedans : tu n'as rien à saisir.

3Lancer l'IA

Deux façons, au choix :

  1. double-clique sur l'icône XozHub.GPT posée sur ton Bureau : l'IA s'ouvre dans une fenêtre de terminal (c'est la façon la plus simple, elle marche toujours) ;
  2. ou ouvre une nouvelle fenêtre cmd et tape :
xozhub

La commande marche ensuite depuis n'importe quel dossier. Si elle n'est pas trouvée, c'est que la fenêtre cmd était ouverte avant l'installation : ferme-la et rouvre-en une.

4Ce qui marche, et ce qui peut bloquer

Vérifié sur une installation réelle. Les autres lignes viennent du code de l'installateur, pas d'une supposition.

Ton casRésultat
Windows 8, 10 ou 11, en 32 ou 64 bitsmarche
Ligne collée dans cmd ou dans PowerShellmarche
Node.js 18 ou plus déjà installémarche
Pas de Node.js, avec winget marche — réponds O à la question ; Windows peut demander une autorisation
Pas de Node.js, sans winget marche après avoir installé Node.js LTS depuis nodejs.org : le message te le dit, puis relance la ligne
Une version plus ancienne est déjà installée marche — l'ancienne est remplacée et ses scripts lisibles effacés
Windows 7 ou antérieur non — Node.js 18 ne s'y installe pas. L'installation le dit et s'arrête proprement, au lieu de t'envoyer dans le mur
Un antivirus bloque les scripts non — utilise le .exe : lui ne télécharge rien
Réseau qui bloque github.com (école, entreprise) non — fais-toi envoyer le .exe ou le .zip
PC d'entreprise verrouillé (logiciels signés obligatoires) non — rien à faire côté installation, c'est la machine qui décide

La ligne a besoin d'internet et d'un dépôt GitHub public. Si ce dépôt est supprimé ou renommé, la ligne ne marche plus pour personne : garde le .exe ou le .zip comme solution de secours.

Ta première demande

Écris en français, avec tes mots, puis appuie sur Entrée. Par exemple :

crée une page de vente pour une appli de gestion de budget, dossier budget-app :
titre accrocheur, trois avantages, une section tarifs avec deux formules, un bouton
d'inscription, et un pied de page. Style moderne, dégradé violet à bleu

Autres façons d'installer

Sert quand la ligne ne passe pas : antivirus, réseau qui bloque GitHub, ou machine d'entreprise.

Un seul fichier XozHub-GPT-Installer.cmd (le plus simple sans internet)

On te l'envoie (Discord, mail, clé USB), tu double-cliques dessus : l'IA s'installe et s'ouvre. Rien n'est téléchargé, donc ni l'antivirus ni le réseau ne peuvent le bloquer.

Un fichier XozHub-GPT-Setup.exe

Double-clique dessus : tout est dedans, rien n'est téléchargé pendant l'installation. Windows affichera « Windows a protégé votre PC » (le programme n'a pas de signature payante) : clique sur Informations complémentaires → Exécuter quand même.

Un dossier ou un .zip du projet

Décompresse le .zip, entre dans le dossier et double-clique sur install.cmd. La clé est déjà dans le dossier : rien à saisir.

Ça ne marche pas ?

« 'xozhub' n'est pas reconnu en tant que commande »

Windows ne relit le chemin des commandes qu'à l'ouverture d'une fenêtre. Ferme celle-ci et ouvre-en une nouvelle, puis retape xozhub. Autre méthode qui marche toujours : double-clique sur le raccourci XozHub.GPT du Bureau.

« XozHub.GPT a besoin de Node.js 18 ou plus »

L'installateur propose de l'installer automatiquement via winget : réponds O. Sinon, installe Node.js LTS depuis nodejs.org, puis relance l'installation.

Erreur rouge tout de suite, la fenêtre n'a rien fait

La ligne n'a pas réussi à télécharger l'installation : ta connexion, un DNS filtrant, ou un réseau qui bloque github.com (école, entreprise). Essaie depuis un autre réseau ; sinon fais-toi envoyer le .exe ou le .zip, qui n'ont besoin d'aucun téléchargement.

« Le fichier d'installation est incomplet ou abîmé »

Le téléchargement s'est mal terminé : relance la même ligne, elle reprend tout depuis le début. Si ça recommence, c'est un antivirus ou un réseau qui coupe le fichier : passe par le .exe.

L'antivirus supprime des fichiers, ou bloque l'installation

Un script qui télécharge et exécute du code, c'est aussi ce que fait un virus : certains antivirus le refusent. Utilise le .exe (il ne télécharge rien), ou demande à l'antivirus d'autoriser le dossier %LOCALAPPDATA%\XozHub.

« Aucune clé API détectée »

La clé X.GPT (xgpt_…) voyage dans le .env du projet : elle s'installe toute seule. Si ce message apparaît quand même, demande une clé à la personne qui t'a donné XozHub.GPT et relance l'installation.

Où est installé XozHub.GPT, et comment le mettre à jour ?

Tout est dans %LOCALAPPDATA%\XozHub (dossier masqué par Windows : c'est normal, tu n'as rien à y faire), et la clé X.GPT est dans le .env de ce dossier. Dans l'interface, la commande /miseajour récupère la dernière version du code et de l'IA, puis redémarre : tu ne perds ni ta conversation, ni tes fichiers de travail.
