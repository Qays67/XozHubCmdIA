XozHub.GPTWindows

Une IA de développement dans une fenêtre de commandes : tu lui écris en français, elle crée les fichiers, exécute les commandes, vérifie et corrige. Installation en une seule ligne.

1Colle cette ligne dans cmd

Ouvre l'invite de commandes (touche Windows, tape cmd, Entrée), colle la ligne ci-dessous (clic droit = coller), puis appuie sur Entrée :

powershell -NoProfile -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/Qays67/XozHubCmdIA/main/install-en-ligne.ps1 | iex"

Laisse la fenêtre ouverte, ça prend une minute. Rien à télécharger à la main, rien à décompresser, rien d'autre à taper. Si une version plus ancienne est déjà installée, elle est remplacée.

2Ce qui se passe

  1. Node.js 18+ est vérifié, et installé automatiquement s'il manque (sinon le lien officiel t'est donné) ;
  2. l'IA est écrite dans %LOCALAPPDATA%\XozHub : le code voyage dans cette ligne, donc rien d'autre n'est téléchargé ;
  3. la commande xozhub est ajoutée, et le raccourci XozHub.GPT posé sur le Bureau ;
  4. le dossier est masqué et n'y contient aucun script lisible : le code y est chiffré ;
  5. la clé X.GPT est fournie dedans : tu n'as rien à saisir.

3Lancer l'IA, et retrouver tes fichiers

Double-clique sur l'icône XozHub.GPT du Bureau — ou, dans une nouvelle fenêtre cmd :

xozhub

Tes fichiers arrivent dans le dossier que tu nommes dans ta demande (« dans le dossier mon-site »), à côté de l'endroit où tu as lancé l'IA. /miseajour récupère la dernière version du code et de l'IA, puis redémarre sans perdre ta conversation.

4Ta première demande

Écris en français, appuie sur Entrée, et laisse faire — chaque commande part toute seule, tu ne confirmes rien. Un premier essai, à copier tel quel :

crée un site vitrine pour un salon de coiffure dans le dossier coiffure-et-vous

Trois choses qui changent tout :

  • donne un nom de dossier — sinon tout se retrouve mélangé dans le dossier courant ;
  • dis à qui ça s'adresse et dans quel style — « pour des parents d'élèves, sobre et rassurant », deux mots suffisent à changer tout le design ;
  • une demande à la fois — tu regardes le résultat, puis tu demandes la retouche.

Ce qui marche, et ce qui peut bloquer

Ton casRésultat

Ligne collée dans cmd ou dans PowerShellmarche

Pas de Node.js, avec winget marche — réponds O à la question ; Windows peut demander une autorisation
Pas de Node.js, sans winget marche après avoir installé Node.js LTS depuis nodejs.org : le message te le dit, puis relance la ligne
Une version plus ancienne est déjà installée marche — l'ancienne est remplacée et ses scripts lisibles effacés
Windows 7 ou antérieur non — Node.js 18 ne s'y installe pas. L'installation le dit et s'arrête proprement
Un antivirus bloque les scripts non — utilise le .exe : lui ne télécharge rien
Réseau qui bloque github.com (école, entreprise) non — fais-toi envoyer le .exe ou le .zip
PC d'entreprise verrouillé (logiciels signés obligatoires) non — rien à faire côté installation, c'est la machine qui décide

La ligne a besoin d'internet et d'un dépôt GitHub public. Si ce dépôt est supprimé ou renommé, la ligne ne marche plus pour personne : garde l'installeur comme solution de secours.

Autres façons d'installer

Sert quand la ligne ne passe pas : antivirus, réseau qui bloque GitHub, ou machine d'entreprise.

Un seul fichier XozHub-GPT-Installer.cmd (le plus sûr sans internet)

On te l'envoie (Discord, mail, clé USB), tu double-cliques dessus : l'IA s'installe et s'ouvre. Rien n'est téléchargé, donc ni l'antivirus ni le réseau ne peuvent le bloquer.

Un fichier XozHub-GPT-Setup.exe

Double-clique dessus : tout est dedans, rien n'est téléchargé. Windows affichera « Windows a protégé votre PC » (le programme n'a pas de signature payante) : clique sur Informations complémentaires → Exécuter quand même.

Un dossier ou un .zip du projet

Décompresse le .zip, entre dans le dossier et double-clique sur install.cmd. La clé est déjà dans le dossier : rien à saisir.

Ça ne marche pas ?

Erreur rouge tout de suite : la ligne n'a rien fait

La ligne n'a pas réussi à télécharger l'installation : ta connexion, un DNS filtrant, ou un réseau qui bloque github.com (école, entreprise). Essaie depuis un autre réseau ; sinon fais-toi envoyer le .exe ou le .zip, qui n'ont besoin d'aucun téléchargement.

« Le fichier d'installation est incomplet ou abîmé »

Le téléchargement s'est mal terminé : relance la même ligne, elle reprend tout depuis le début. Si ça recommence, c'est un antivirus ou un réseau qui coupe le fichier : passe par le .exe.

L'antivirus bloque ou supprime des fichiers

Un script qui télécharge et exécute du code, c'est aussi ce que fait un virus : certains antivirus le refusent. Utilise le .exe (il ne télécharge rien), ou autorise le dossier %LOCALAPPDATA%\XozHub.

« 'xozhub' n'est pas reconnu en tant que commande »

Windows ne relit le chemin des commandes qu'à l'ouverture d'une fenêtre : ferme-la et ouvre-en une nouvelle, puis retape xozhub. Ça marche toujours aussi : double-clique sur le raccourci XozHub.GPT du Bureau.

« XozHub.GPT a besoin de Node.js 18 ou plus »

L'installation propose de l'installer pour toi : réponds O (Windows peut demander une autorisation). Sinon, installe la version LTS depuis nodejs.org, puis relance la ligne.

« Aucune clé API détectée »

La clé X.GPT (xgpt_…) voyage dans l'installation : elle se pose toute seule. Si ce message apparaît quand même, demande une clé à la personne qui t'a donné XozHub.GPT, puis relance l'installation.
